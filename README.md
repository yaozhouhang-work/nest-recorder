# 巣記録 Nest Recorder（試作版 v0.14.2）

スマホのブラウザで使う野外の巣記録ツール。iPhone / Android どちらでも動きます。

**開く：** https://yaozhouhang-work.github.io/nest-recorder/
（「ホーム画面に追加」するとアプリのように使え、データも消えにくくなります）

## できること

- 地図（地理院 標準・写真 / OSM）と GPS で巣の位置を登録、ドラッグで修正
- 巣ごとの確認記録（日時・状態・卵数・雛数・親鳥・写真番号）
- すべての修正を履歴に残す
- 書き出しは ZIP 1 つ（CSV 3 件 + My Maps 用 KMZ）。読み込みは ZIP / CSV / KMZ（複数人の記録の統合にも使用）
- Google My Maps の KMZ 読み込み・書き出し（巣データ / 補足データ を区別）
- 任意：My Maps 連携（前回以降の追加・修正分だけを KMZ にして My Maps に取り込む）
- 日本語 / 中文 / English

## データについて

データはその端末のブラウザ内にだけ保存されます。**調査のたびに必ず CSV を書き出してください。**
未書き出しの変更は画面上部に赤く表示され、一定件数ごとと起動時に書き出しを促します。

このリポジトリにはプログラムだけを置き、巣の位置データは置きません。
